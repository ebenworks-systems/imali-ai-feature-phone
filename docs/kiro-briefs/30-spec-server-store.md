2. Routes, exactly as in .kiro/steering/tech.md: POST /ussd (Africa's Talking form fields, answers text/plain from handleUssd), POST /sms (Africa's Talking incoming text: from, to, text, date, id; answers with the reply text in the body, and also sends it back through Africa's Talking's SMS API when AT_USERNAME and AT_API_KEY are set, to the sandbox host when AT_USERNAME is "sandbox"), POST /api/phone/ussd and POST /api/phone/sms (JSON for the browser phone: { phone, sessionId?, text } in, { response } or { reply } out, plus the character count and the limit so the page can show them), GET /api/ledger?phone=...
